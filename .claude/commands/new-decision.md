Create a new product/business decision record (NOT an architecture decision — use /new-adr for those).

Steps:
1. Create docs/decisions/YYYY-MM-DD-<slug>.md from docs/templates/decision.md, using today's date and the slug from the command argument.
2. Fill in the frontmatter (title, date, decided-by) and the Context / Decision / Why / Consequences sections from the conversation.
3. Add a newest-first entry to the Index in docs/decisions/README.md.
4. Do NOT auto-commit — decision content is governance/financial-adjacent. Tell the user it's written and let them decide when to commit.
5. Open the file for review.
