## Shipped this week

- **Phase A — identity module: Definition of Done closed.** Backend was already
  code-complete (78 tests, models 93% / services 96% coverage, ruff + mypy + import-linter
  green); this week walked the rest of the DoD.
- Ran the full golden-path smoke test against the live dev stack over real HTTP (CSRF +
  sessions + allauth verification): register parent → confirm email → login → `GET /me/` →
  add child → create invite, then register adult student → confirm → login → accept invite

  `SessionAuthentication` behaviour, not a regression.

  pre-commit pinned v0.6.0 while CI floated to 0.15.16 — failed `ruff format --check`;
  pinned both, and installed the backend pre-commit hooks (they were never installed).
  (3) First deploy failed on staging-DB `InconsistentMigrationHistory` (account before
  identity); recreated the empty staging DB and re-deployed green.
- **Email (ADR-0016).** A live staging smoke test found `register` → 500: production had
  no SMTP config. Added env-driven SMTP settings + AWS SES, deployed, and re-tested live:
  register → 201, login-before-verify → 400, unauth → 403. Phase A DoD fully closed.
