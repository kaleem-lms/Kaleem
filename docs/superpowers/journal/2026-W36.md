## Decisions made (link ADRs)

- **[ADR-0026](../../adr/0026-coverage-ratchet-not-aspirational-100.md) — coverage is a
  ratchet floor CI enforces, not an aspirational 100%.** Partially supersedes ADR-0021's
  clause 1. The floor may only go up; **lowering it requires an ADR**. 100% stays the target.
  ADR-0021's e2e clause is explicitly marked **not yet in force** — no Playwright harness
  exists anywhere — and `CLAUDE.md` D3/D9 now say so.
  - The honest framing: this **lowers the stated standard** (100 → 92/97). It trades a number
    nobody enforced for a smaller one everybody does. Recorded as a retreat, not as progress.
  - Root cause worth remembering: the gate stayed off for three months because turning it on
    would have failed every unrelated PR, so the honest answer was always "not this PR". A
    gate whose entire adoption cost lands on whoever touches it next never gets adopted.
    Setting the floor to *what already passes* makes adoption free.
