# `brand-assets/` — Kaleem brand & product-surface assets

Each entry ships as `<stem>.svg` + `<stem>.png`. See [`../ASSET-INDEX.md`](../ASSET-INDEX.md) §3.

| Stem | Use |
| --- | --- |
| `brand-mark-{light,dark}` | Large standalone mark for brand moments |
| `social-avatar-{light,dark}` | Square social profile image |
| `social-cover-{en,ar}-{light,dark}` | Social profile cover/banner (~3:1) + tagline |
| `og-image-{en,ar}-{light,dark}` | `og:image` / `twitter:image` (1200×630) |
| `email-header-{en,ar}-{light,dark}` | Email masthead band (~1200×300) |
| `email-logo-{light,dark}` | Compact email-signature logo |
| `splash-{en,ar}-{light,dark}` | App/PWA launch splash (static frame) |
| `loading-{en,ar}-{light,dark}` | In-app loading state (logo + gold arc) |

**Rules:** warm cream / near-black backgrounds (never pure white/black); gold used once;
bilingual parity (AR is designed, RTL-mirrored). Splash/loading have reduced-motion-safe
static frames.
