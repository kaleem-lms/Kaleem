# `marketing/` — Kaleem marketing & landing graphics

Each entry ships as `<stem>.svg` + `<stem>.png`. See [`../ASSET-INDEX.md`](../ASSET-INDEX.md) §4.

| Stem | Use |
| --- | --- |
| `hero-illustration-{light,dark}` | Landing hero scene (guided learning) |
| `feature-sessions-{light,dark}` | Feature: 1-on-1 & group live sessions |
| `feature-progress-{light,dark}` | Feature: progress tracking |
| `feature-curriculum-{light,dark}` | Feature: Quran & curriculum |
| `dashboard-preview-{light,dark}` | Product dashboard preview graphic |
| `landing-hero-{en,ar}-{light,dark}` | Full branded hero block (headline + CTA + art) |
| `presentation-cover-{en,ar}-{light,dark}` | Pitch-deck / slide cover (16:9) |

**Rules:** flat vector illustration, warm limited palette (emerald/gold/cream + 1–2 muted
supports), generous negative space, people modest & respectfully depicted, education-focused
(never generic "tech"). Dark variants use emerald `#4FB89F` / gold `#D9B43C` on `#0E1715`.
